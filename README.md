# SmartFactory IoT — Protocol Integration Assignment

This project implements the **MQTT** and **CoAP** parts of the SmartFactory IoT assignment. AMQP is intentionally skipped because the provided assignment copy marks AMQP as ignored.

## Implemented files

| Task | File | Status |

## Important note about packet loss

`generate_qos_table.py` can run in two modes:

```text
python scripts/generate_qos_table.py
```

or, on Linux/WSL with `tc` available:

```text
python scripts/generate_qos_table.py --apply-netem --loss-percent 10
```

MQTT runs over TCP, so ordinary packet loss on the loopback interface may be recovered by TCP before MQTT sees it. Use the generated measurement note in `report/comparison_report.md` so the report is honest about how the table was produced. The QoS script auto-starts the CoAP server if needed and counts duplicates as repeated MQTT sequence numbers and repeated CoAP response Message IDs.

# Run Project Step by Step

## Step 1 — Create and activate the Python environment

### Windows PowerShell

```text
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

If PowerShell blocks activation, run once:

```text
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### Ubuntu / WSL terminal

```text
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

---

## Step 2 — Start Mosquitto only

This project needs the MQTT broker for Task 1.

```text
docker compose up -d mosquitto
```

Check it:

```text
docker compose ps
```

You should see `smartfactory-mosquitto` running and port `1883` exposed.

---

## Step 3 — Check your environment

```text
python scripts/environment_check.py
```

Fix any `[FAIL]` lines before continuing.

---

## Step 4 — Generate the QoS table automatically

This command starts the CoAP server automatically if it is not already running. It also counts duplicates: MQTT duplicates are repeated sequence numbers, and CoAP duplicates are repeated response Message IDs.

Normal local measurement:

```text
python scripts/generate_qos_table.py
```

Linux/WSL measurement with 10% loopback packet loss:

```text
python scripts/generate_qos_table.py --apply-netem --loss-percent 10
```

The script writes:

```text
report/qos_measurements.json
report/qos_table.md
report/comparison_report.md
```

Then open `report/comparison_report.md` and verify Section 5.1. The detailed raw values are also saved in `report/qos_measurements.json`.

---

## Step 5 — Capture MQTT and CoAP packets automatically

This command also starts the CoAP server automatically if it is not already running.

Default for Ubuntu/WSL:

```text
python scripts/capture_packets.py
```

If capture files are empty, list interfaces:

```text
tshark -D
```

Then pass the correct interface number or name:

```text
python scripts/capture_packets.py --interface 1
```

The script writes:

```text
captures/mqtt.pcap
captures/coap.pcap
```

---

## Step 6 — Generate the packet-analysis report automatically

```text
python scripts/analyze_packets.py
```

The script writes:

```text
report/packet_analysis.md
report/packet_analysis_values.json
```

---

## Step 7 — Run the required tests

```text
python -m pytest tests/ -v --tb=short
```
